# Commits

- Use Conventional Commits: `<type>(<optional scope>): <description>`
  - types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `perf`, `build`, `ci`, `style`
  - optional scope: `ios`, `renderer`, `build`... e.g. `feat(ios): add image component`
  - short description, imperative mood, lowercase, no trailing period, in English
- Never add `Co-Authored-By` or any attribution trailer.
