# Brand

nativue (said "native view"), always lowercase in the wordmark. Logos: `.github/logo-horizontal*.svg`.

Colors:

| Name        | Hex       | Use                                                       |
| ----------- | --------- | --------------------------------------------------------- |
| Ink         | `#0B1220` | text, dark backgrounds, "nati" in the wordmark            |
| Mint        | `#4AF2AE` | phone gradient start; "vue" on dark backgrounds           |
| Sea green   | `#10B39B` | phone gradient end                                        |
| "vue" green | `#0E9F84` | "vue" in the wordmark; accents on light backgrounds       |
| Mist        | `#F1F5F9` | light backgrounds; the "V" on dark backgrounds            |

Font: Inter Display Bold, letter spacing -2%.

The demo's `src/lib/theme.ts` and the template's starter screen use these colors.
